This Directory contains instructions on how to run the bm25 scipts we used for our reproduction study. Also in this Directory you can find a standard bm25 scipts ready for use to test the performance. In our Experience, the results from this scripts are signifcantly lower than the results from the Elasticsearch implementation. But it is a nice starting point. 

The following link contains the github repository from which we got the Elasticsearch bm25 implementation. All the information you need to run the scipts can be found in that repository: <a href="https://github.com/beir-cellar/beir/blob/main/examples/retrieval/evaluation/lexical/evaluate_bm25.py">LINK </a>.
